# The 22 analysis levels (full detail)

Each level returns `{ level, name, score 0–100, issues[] {severity, impact, message, element, fix, evidence}, data{} }`.
Overall score = mean of all levels. A crashing level yields score 0 + one critical issue — never a failed audit.

| #   | Name                                               | What it measures (real page signals)                                                                                                                                                       |
| --- | -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | Core Hygiene & Technical Baseline                  | Title length/pixels/truncation, meta description, viewport, robots meta + X-Robots-Tag, canonical integrity, H1 count/skips, alt coverage, response headers, internal link quality/density |
| 2   | DOM Reality, Rendering & Structural Diagnostics    | SSR vs CSR diff (raw vs rendered), node count/max-depth/histograms, JSON-LD validation (valid/invalid/missing props/circular refs)                                                         |
| 3   | Semantic Architecture, Entities & Information Gain | Words, Flesch-Kincaid, keyword density, bigrams, transitions, structure, KL-divergence vs baseline corpus (`N/A` without one), entity extraction                                           |
| 4   | Generative Search, LLM & RAG Visibility            | RAG chunk simulator + retrievability, passage vectors, direct-answer scorer, citation heuristics (labeled heuristic — no LLM run), entropy                                                 |
| 5   | Dev Automation & Auto-Fix Generation               | Patch diffs (schema/headings/canonical), regression tests, rollback plan                                                                                                                   |
| 6   | Edge Computing & Serverless Integration            | Worker codegen, security headers, cache policy, CORS, cookies, mixed content                                                                                                               |
| 7   | Multi-Modal Content & Spatial Asset Auditing       | Images (alt/dims/lazy/srcset/formats), video captions/posters, audio transcripts, SVG a11y                                                                                                 |
| 8   | Predictive SERP Volatility & Algorithm Impact      | Volatility from structure, thresholds, feature readiness (AI Overview/snippet/PAA/local/shopping/panel), E-E-A-T, resilience                                                               |
| 9   | SEO A/B Testing & Rollback Safety                  | Baseline, testability, title/meta variants, rollback, significance math (CTR uplift `not measured` — no test run)                                                                          |
| 10  | Bot Behavior Mapping & Log Config Templates        | Status/redirects (latency `not measured`), crawl budget, freshness, Cloudflare/CloudWatch/Datadog **templates**                                                                            |
| 11  | Synthetic Content & LLM Visibility Heuristics      | Agent behavior, RAG sim, CTA/form/JS readiness (heuristics, no LLM inference)                                                                                                              |
| 12  | Algorithmic Quality & Helpful-Content Classifier   | Freshness, E-E-A-T, thresholds, flags, helpful-content alignment                                                                                                                           |
| 13  | Edge-Native Patching & CI/CD Gatekeeping           | Pre-commit, GitHub Actions, GitLab CI, edge deploy code, self-heal rules                                                                                                                   |
| 14  | Financial Attribution — Single-Page ROI            | Revenue-at-risk per issue, ROI, quarterly, action plan — **THIS page**, GA4-gated (`$0` + note without inputs)                                                                             |
| 15  | Passage Vector & Cosine Similarity Profiler        | Passage retrieval, entity flow, heading drift, clustering, doc distance                                                                                                                    |
| 16  | Third-Party Consensus & Entity Alignment           | Consensus, citation quality, panel readiness, claims, trust                                                                                                                                |
| 17  | Autonomous Fix Generator & Red-Team Checks         | Validated fixes + red-team header/HTML abuse checks                                                                                                                                        |
| 18  | Zero-Click & Agentic Commerce Visibility           | AI Overview/snippet readiness, product schema, commerce signals, brand share                                                                                                               |
| 19  | Edge Orchestration & Self-Correction Rules         | Canary rollout, rollback triggers, error budgets, self-correction (deploy estimates honest)                                                                                                |
| 20  | Adversarial Checks & Security Header Audit         | Headers, disclosure, cloaking (unmeasurable vectors reported skipped)                                                                                                                      |
| 21  | Site-Wide Risk Aggregation & Executive Rollup      | Portfolio rollup of title/canonical/headings/schema/links + executive risk (portfolio scope)                                                                                               |
| 22  | **AI-Search Readiness (NEW 1.3.0)**                | **llms.txt presence/quality, robots.txt AI-bot rules (GPTBot/PerplexityBot/ClaudeBot/CCBot/…), canonical/title/description/JSON-LD citation surface, definitional lead sentence**          |

Scope notes (by design): L14 = this URL's dollars; L21 = portfolio rollup. L5/L13/L17/L19 = PR diffs vs CI gates vs red-team vs safe rollout.
